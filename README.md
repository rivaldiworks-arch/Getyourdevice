# Neuro Commerce MVP

MVP web commerce yang bisa dijalankan langsung tanpa backend.

## Fitur
- Storefront / katalog produk
- Search produk
- Cart
- Checkout
- Pilihan pembayaran simulasi
- Admin upload produk + foto
- Edit / hapus produk
- Stok
- Order management
- Update status order
- Data tersimpan di browser dengan localStorage

## Menjalankan
1. Extract ZIP.
2. Buka `index.html` di browser.
3. Klik menu `Admin` untuk tambah produk.
4. Klik `Store` untuk simulasi pembelian.

## Catatan
Versi ini adalah MVP lokal. Untuk production, upgrade yang disarankan:
- Backend + database (Supabase/PostgreSQL)
- Login admin/customer
- Cloud image storage
- Midtrans/Xendit payment gateway
- RajaOngkir/Biteship shipping
- Domain + hosting
- WhatsApp notification
